# Market List

A small, responsive shopping list built with HTML, CSS, and vanilla JavaScript.

## Features

- Add items with optional prices
- Select one or more items and mark them as purchased
- Click an item name to toggle its purchased status
- Edit item names and prices, or remove individual items
- See the total price of purchased items update as you shop
- Clear the list and save or restore it through browser local storage
- Responsive layout with keyboard accessible controls

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required. List data stays in local storage in that browser and on that device.

## Publish

Push this repository to GitHub, then enable GitHub Pages in the repository settings and choose the branch and root folder containing `index.html`. GitHub will provide a public website URL to submit for the assignment.
